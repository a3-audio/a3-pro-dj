# Set structure: the phases of a night, mood, and movement

How a DJ set is shaped over a night, and how movement in the room can follow that shape. This is the
knowledge A³ Motion's shipped library (its sets, clips and actions) was built on, written 2026-09-28
to 2026-10-03. For what the ear can follow at all, see
[motion perception](../spatial/motion-perception.md); for how much to move at once, see
[playing in 3D](../spatial/playing-in-3d.md).

## The phases of a night

A³ names its sets after the phase of the night they are for, so a set list reads like a running order:

`Warmup · Groove · Build · Peak · Drop · Break · Dub · Deep · Float · Closing`

| Phase | Movement character |
|---|---|
| Warmup | slow, high, open |
| Groove | jumps on the beat grid, at ear height |
| Build | opening, speeding up, rising |
| Peak | wide, fast, lifted |
| Drop | hard, angular, close |
| Break | still, suspended, drawn in |
| Dub | throws, swings, near and far |
| Deep | low, slow, dark |
| Float | overhead, slow, smooth |
| Closing | descending, slowing, settling |

Four moods were added later as their own sets (2026-10-03): **Tribal** (percussive, close to the
ground, call and answer), **Acid** (one figure turning slowly, resonance), **Ambient** (weather), and
**Tension** (siren), plus **Space** — the set to use when the room should *hear* the movement (see the
[MJ playbook](../spatial/mj-playbook.md)).

Each phase has an obvious next phase, and a performer wants a single press that takes them there
on the downbeat. In A³ that is the **Cue** pad: Warmup → Groove → Build → Peak → Drop → Break → Build
again; Dub → Deep → Float → Closing → Warmup. Two escapes exist in every library: a **dub escape** and
an **emergency calm**.

## Build-up, drop, breakdown

- **The build** widens, rises and opens the filter, and speeds up.
- **The drop** releases it all at once — on the one.
- **The breakdown** strips it back.
- **Call and response** between a narrow and a wide sound is a standard drop device.

A movement that follows this: widen and lift during the build, snap to the front (or freeze) on the
drop, pull in and slow down in the breakdown. See [spatial FX](../spatial/spatial-fx.md) for the
riser and drop gestures in 3D.

## Mood: energy and pleasantness

The mood meter (Yale's RULER tool, on Russell's circumplex model) uses the two axes music-emotion
research uses throughout: **energy** (arousal) and **pleasantness** (valence).

| | unpleasant / tense | pleasant / open |
|---|---|---|
| **high energy** | driving, dark, industrial | euphoric, peak, hands-up |
| **low energy** | brooding, suspended, deep | calm, floating, arriving |

What research and practice say about movement and mood:

- **Speed and regularity carry energy.** Faster rotation and tempo-locked rates read as more energetic.
  Far above the hearing limit for rotation, movement stops being heard as movement and becomes a
  vibrating texture (Stockhausen's rotation work).
- **Approach (looming) raises arousal.** Loudness increase is the strongest cue, then the direct-to-
  reverberant ratio. Approaching sounds are rated more arousing and more unpleasant than receding
  ones, most of all for sounds that are already negative.
- **Height carries lift.** Listeners map high to up; moving elements upward reads as the section
  getting bigger. Low and under the floor reads as weight, darkness and pressure.
- **Club reality.** In club music, panning is mostly subtle and purposeful, because many systems are
  effectively mono. Movement works best tempo-synced; free-running LFOs drag against the groove. Dub and
  dub techno use the mixing desk as the instrument: sends, sweeps, throws.

| Movement parameter | more energy | less energy | more open | more tense |
|---|---|---|---|---|
| speed / spin | faster | slower | | |
| shape | angular (corner, square, zigzag, star) | smooth (circle, ellipse, rose, lissajous) | continuous curves | angular, jumps |
| end of a pass | bounce, random | loop, pause | loop, forward | reverse, bounce |
| height | | | up, overhead | down, towards the floor |
| reach | wide (throws) | narrow | wide, enveloping | narrow and close (looming) |
| accent attack | fast (it hits) | slow (it swells) | | |
| filter resonance | | | low | high |
| sway / swell cycles | fast | slow (8–32 bars) | | |

## Vocabulary for moving sound

Movement needs words a performer can say. Two sources give them:

- **Smalley's spectromorphology** names the basic motions of electroacoustic music: ascent and descent;
  oscillation (between two points); rotation around a centre; flying out from or in to a centre
  (centrifugence, centripetence); dilation and contraction; vortex. Each became a shape or an action in
  A³ Motion.
- **Rhythm cells.** The tresillo (3+3+2 in eighths) is the cell EDM builds tension on before a drop; the
  son clave 3-2 has three strokes in bar one and two in bar two. A position that jumps on those
  sixteenths grooves in space.

## One panel layout, every set

The hands should learn one panel, not one per set. A³ Motion's six action pads keep the same meaning in
every set:

| | left: **more** (open, up, faster) | right: **less** (close, down, calmer) |
|---|---|---|
| row 1 | gentle more | gentle less |
| row 2 | strong more | strong less |
| row 3 | the sound effect (FX) | Cue into the next phase |

"Left adds energy, right takes it away; top gentle, middle strong, bottom special" is the single most
useful sentence for a first night, and it belongs in the quick start.
