# a3-pro-dj — the A³ pro-DJ

**Status 2026-10-17: planned, no code yet.**

The pro-DJ of [A³ Audio](https://github.com/a3-audio/a3-system) as an application of its own: the
set seen from the floor centre, inside the sphere, with the ships, bands and groups of A³ Motion
moving all around and the beat in view; head tracking over OSC. Later it plays along — as autopilot,
co-pilot beside a human DJ, or a training game — by conducting StemDeck and Motion's pilots through
A³ Core, never as a second brain on a deck.

It reads what A³ Core and A³ Motion already send over OSC; it produces no audio.

**Documentation: https://a3-audio.github.io/a3-doc/**
